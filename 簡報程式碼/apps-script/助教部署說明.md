# AI 助教：開通步驟（約 10 分鐘，只要做一次）

金鑰只放在你自己的 Google 帳號裡，網站上看不到。請不要把金鑰貼給任何人，包括 Claude 對話。

## 1. 建立紀錄用的試算表
1. 開 Google 雲端硬碟 → 新增 → Google 試算表，取名「培訓助教紀錄」。
2. 上方選單「擴充功能」→「Apps Script」。
3. 把 `tutor.gs` 整段複製貼上（取代原本的內容）→ 按存檔（磁片圖示）。

## 2. 放金鑰和通行碼
1. Apps Script 左邊齒輪「專案設定」→ 拉到最下面「指令碼屬性」→「新增指令碼屬性」。
2. 新增兩個：
   - `CLAUDE_KEY`：你的 Claude 金鑰（console.anthropic.com → API Keys，`sk-ant-` 開頭）
   - `PASS`：助教通行碼，自己想一個，至少 6 個字（網站第一次用要輸入）
3. （可不填）`DAILY_LIMIT`：每天最多幾次，不填＝40 次。

## 3. 部署
1. 右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**所有人** → 部署。
3. 第一次會要你授權：選自己的帳號 →「進階」→「前往（不安全）」→ 允許。
   （會用到：讀寫這個試算表、連到 api.anthropic.com）
4. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`），貼給 Claude。
   這個網址不是祕密，別人沒有通行碼也用不了。

## 4. 設花費上限（很重要）
console.anthropic.com →「Settings」→「Limits」→ 設每月上限（例如 US$15）。超過 Claude 會自動停，不會多扣錢。

## 之後
- 要改通行碼：改指令碼屬性 `PASS`，網站會請你重新輸入。
- 問答紀錄在試算表的「提問紀錄」，要問老闆的清單在「要問老闆」。
- 程式更新：整段重新貼上 → 存檔 →「部署」→「管理部署作業」→ 鉛筆 → 版本選「新版本」→ 部署（網址不變）。
